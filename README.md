## 🛰️ Mission
Two lunar images. One question: **are they the same location, and what changed between them?**
Lunaris registers the images, aligns them, and highlights surface change over time.

## 🧭 Flight Path
`Raw image → CLAHE → SIFT/ORB → KNN + Lowe's ratio → RANSAC + Homography → RMSE → SSIM + morphology → Change map`
